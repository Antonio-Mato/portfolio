Asclepius AI

A medical assistant that can see, triage, and guide

A medical assistant grounded in real clinical literature rather than model memory. Field manuals and first-aid references are chunked, embedded and stored in a vector database, so each answer is retrieved from verified sources before it is written. It reads uploaded images for visual triage, screens every message for emergency red flags, and deliberately reports an urgency level instead of a diagnosis, then maps the recommended specialty to real clinics near the user.

Mato's Adventures

A 2DA 2D RPG, engine and all, built by hand

A full 2D role-playing game built entirely in JavaFX with no game engine, no libraries, nothing but the standard toolkit. Every system was written from scratch: an AnimationTimer frame loop driving a raw Canvas renderer, a tile map parsed into its own collision grid, movement resolved axis by axis so the player slides along walls instead of catching on them, four-direction sprite animation, a camera that scrolls the world around the player, branching NPC dialogue, and a logic-riddle puzzle system that gates progression.
